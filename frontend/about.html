StudentGuard AI

An AI-based Student Dropout Risk Prediction System designed to analyse relevant student information and classify predicted dropout risk into Low, Medium, or High levels.

Project Overview

StudentGuard AI is a machine-learning based academic support application developed to analyse student-related factors and generate a dropout-risk prediction.

The system considers academic, attendance, engagement, financial, support, and other relevant student attributes before generating a prediction.

How the System Works

1. Student Information

Student-related academic, attendance, engagement, financial and support information is provided to the system.

2. Machine Learning

The trained machine-learning model processes the supplied features and produces a prediction.

3. Risk Result

The system presents the predicted risk level and dropout probability.

Risk Categories

Low Risk

Lower predicted dropout probability based on the model's classification threshold.

Medium Risk

Intermediate predicted dropout probability requiring attention and monitoring.

High Risk

Higher predicted dropout probability based on the configured model threshold.

Machine Learning

The project uses supervised machine-learning classification for dropout-risk prediction.

The implemented model pipeline performs preprocessing of numerical and categorical features before generating predictions.

The project includes:
  • Logistic Regression
  • Random Forest
  • Numerical feature preprocessing
  • Categorical feature encoding
  • Model evaluation and comparison

Dataset

The current project uses a synthetic dataset created for the StudentGuard AI project.

The dataset contains approximately 1,000 student records with academic, attendance, engagement, financial, support and related attributes.

Because the dataset is synthetic, the predictions should be treated as project and demonstration results rather than predictions validated on real institutional student data.

Important Note
StudentGuard AI is an academic/project-oriented student dropout risk prediction system. Its predictions are intended to support analysis and early identification of potentially concerning patterns. The prediction should not be treated as a definitive determination that a student will drop out.
